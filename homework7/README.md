# Homework 7: Interactive DOM Project

**Student:** Algassimu Bangura

## Study Planner

Open `index.html` in a browser. No installation or build step is needed.

1. Click **Give me motivation** to change the visible encouragement message. `script.js` uses `addEventListener('click')` and `textContent`.
2. Type into **Today's focus**. The preview updates immediately and turns green through an `input` listener and `classList.toggle`. Clearing the input resets its text and style.
3. Enter a task and select **Add task** (or press Enter). JavaScript creates list elements using `createElement` and adds them using `appendChild`. Each task has a **Delete** button.
4. JavaScript is in `script.js`, CSS is in `styles.css`, and there are no inline event handlers. User input is inserted with `textContent`.

Blank or whitespace-only tasks are rejected. The page supports keyboard controls, visible focus indicators, labeled inputs, and status announcements. Tasks are temporary and reset on reload.
