# Algassimu Bangura — Personal Portfolio Milestone

This repository contains the HTML foundation for a three-page personal portfolio website.

## Files

- `index.html` — Home page
- `projects.html` — Projects/Work page
- `about.html` — About/Contact page
- `portfolio-wireframe.png` — Digital wireframe for all three pages, including the planned colors and fonts

## Design Plan

- **Colors:** Navy (`#12355B`), teal (`#2A9D8F`), off-white (`#F7F7F2`), and charcoal (`#252525`)
- **Fonts:** Poppins for headings and Arial for body text

No CSS is included in this milestone. The focus is semantic HTML, page structure, heading hierarchy, and working relative navigation.
